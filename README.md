# b005. 長條圖(右至左)

## 內容
請在一列（row）之中輸入多個正整數，接著依據這些正整數，繪出由右至左以星號（*）為符號的長條圖。對於數字 
，就必須繪出具有 
 個星號（*）的橫長條。所有的長條呈現時，對齊最右邊。

## 輸入說明
輸入的正整數之間是以空白隔開，其數量不定，但不會超過10個。

## 輸出說明
每一個數字皆構成一列（row）的星號（*）。各長條向右對齊時，若該列的左邊仍有空位，則以空白補足。

## 範例輸入
1 9 8 7 3 6

## 範例輸出
        *
*********
 ********
  *******
      ***
   ******
